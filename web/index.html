AI MODEL #1 + #2

What each model actually does

01

Random Forest · Flood prediction

Predicts probability that a node floods in the next 30 minutes using rainfall, level rise, outgoing flow and model residuals.

At T+60 the original dashboard showed 0.39. That is below its 0.80 threshold.
02

Isolation Forest · Anomaly detection

Scores unusual depth and flow behaviour relative to a healthy network. It does not directly identify which pipe is blocked.

03

Hydraulic Digital Twin · Blockage localisation

Re-runs SWMM with different conduit openings and fits them to sensor measurements. It estimated C3 at about 72% blocked in the recorded T+60 snapshot.

HOW TO EXPLORE

Your StormTwin workspace

1. Open Network Twin and use the play controls to watch a real SWMM-generated storm replay. Select any pipe/node to inspect recorded telemetry.

2. Open IoT Monitoring to see actual stored sensor values and quality flags, including missing packets and the scripted J2 sensor failure.

3. Open Mitigation Lab and compare interventions. At minute 60, the default comparison matches the original project screenshots. For changed inputs, click Calculate with real SWMM after installing the Python dependencies.

4. See AI Diagnostics for separate machine-learning and hydraulic-twin results, and Architecture for the implementation.

This entire interface is a simulated project demonstration, not a field-connected monitoring service.
